# Build Anything — Class Agenda (for kids, 14–17)

## From Game Worlds to the Real World

**Format:** half / full day. **Each student vibe-codes and deploys their *own* app.** Deck: 39 slides.

**The theme (woven through every section):** You already build worlds in Roblox and Minecraft — you didn't wait, you *made* the game. **AI lets you do that same thing in the real world.** Same builder instinct, bigger canvas. Every section returns to this flip — *from game worlds to the real world.*

**Through-line #2 (the how):** **DOER vs CHECKER.** Every good build has someone *doing* and something *checking*. With AI you're the director — you set up both.

**The memory arc:** the context window is just *short-term memory* → great builders give the AI **four kinds of memory: short-term (context + `MEMORY.md`), long-term (docs · wiki · specs), semantic (searchable past), and live (MCP)**. The long-term one is detailed later on the `/docs` slide.

**Visual style:** Mithril look (navy `#03050C`, cyan→violet→gold gradients, Outfit/Inter/JetBrains-Mono), playful and readable, one idea per slide, **every diagram animated.** Title: **Build Anything.**

> Sources mined: **roblox_dev**, **mithril** (context-engineering + styling), **harness_upgrade** (agent loop, memory/lessons, reviewer gate, dev→main deploy, model routing, DOER/CHECKER).

## Section 0 — Overview
1. **Title** — Build Anything · *From game worlds to the real world.*
2. **What is AI** — the flip, as a story (waited for games → Roblox/Minecraft → AI builds the real world).
3. **Player vs Builder** — "you already did it in Roblox; tonight you do it for real."
4. **How AI works** — animated pipeline: data → tokens → layers of math → answer.

## Section 1 — Fundamentals
5. **First-principles thinking** — what *is* a game? = what *is* an app? Same bones.
6. **Systems** — animated: User · Front End · Database · Interface. "A Roblox game and a real app have the same skeleton."
7. **Math is the language of AI** — ~2 slides, secret-code framing.

## Section 2 — Coding with AI *(ordered for the memory arc)*
8. **You + AI, building together** — animated conversation: instructions flow to the AI ("make it blue," "smaller"), code/answers flow back ("done ✓"). Not a handoff — you steer, it builds. *You're the director; the AI is the crew.*
9. **Context = short-term memory → the three memories** — Short-term (context + `MEMORY.md`), Long-term (docs · wiki · specs), Semantic (searchable past).
10. **MCP = the 4th memory (live)** — walkie-talkie between the AI and a live app; what's true *right now*. "Short-term · long-term · semantic · live."
11. **Three tools, three jobs** — Cursor, GitHub, Vercel.
12. **Detail slide per tool.**
13. **Keystroke → live app** — "the real-world version of hitting Play in Roblox."

## Section 3 — Setup (hands-on)
14. Setup Cursor (macOS update, `xcode-select --install`, install).
15. Setup GitHub (account, Git, first commit/push).
16. Setup Vercel (sign up with GitHub, import, deploy).

## Section 4 — Vibe-code *well*
17. **The harness** — safety gear + pit crew around the race-car app.
18. **`/docs` brain** — the long-term memory: specs · plans · decisions · lessons.
19. **A spec is a contract, not vibes** — define "done" first.
20. **The loop** — Brainstorm → Spec → Plan → Build → Review → Test → Ship (DOER/CHECKER).
21. **Teach it from mistakes — the lesson habit** — symptom → cause → rule.
22. **The reviewer with teeth** — APPROVE / BLOCK.
23. **Prove it works** — tests; "if the smoke test is red, don't ship."
24. **Right brain for the job** — smart model to think/review, fast model for grunt work.
25. **Cursor best practices** — small asks, read the diff, keep it simple, commit when it works.

## Section 5 — Deploy & verify
26. Deploy to Vercel — push → build → live link.
27. Preview vs Production — every branch a preview link; `main` is live; *you own the deploy.*
28. Verify — open on your phone, share it. *You built something real.*

## Section 6 — Bonus
29. Waves — many AI agents in parallel, each reviewed.
30. Self-healing builds & goal loops.
31. Build games too — full circle to Roblox + link.
